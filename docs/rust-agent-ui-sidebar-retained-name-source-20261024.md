# Sidebar retained-name source slice (#22)

This change adds the canonical retained-name input required by the ranking design. The source slice itself does not add ranking; subsequent binding/projector/demo consumption is described in `rust-agent-ui-sidebar-ranked-search-20261024.md`.

`tekes-agent-presentation` now exports `SidebarNameDocument` and `SidebarNameCorpus`. The DTOs are serde camelCase, contain only endpoint/session identity and title plus endpoint/connection/inventory metadata, and have no SQLite or runtime dependency. `SidebarNameCorpus::validate` checks a nonempty unique endpoint domain containing the source endpoint and unique, nonempty document addresses scoped to that source endpoint. Epoch zero is valid. Validation is structural and does not confer authority.

The same crate exports `canonical_session_title`. Binding inventory rows wrap this helper, so visible rows and the retained corpus share trimming, legacy `title`/`name`, `New conversation`, and explicit projected-clear behavior.

The public inventory frame now includes `nameCorpus` and a same-snapshot top-level `connectionEpoch`. `SharedAgent` constructs it from the exact `MemoryProjectionStore` reference used for `sessions`, with the sorted IDs of every registered endpoint as the endpoint domain. Its documents include every retained store session with an object summary, including archived, subagent, and ephemeral records; sessions without a summary are omitted, while a malformed non-object summary returns a protocol error. It does not alter the existing `sessions` membership, read history, query a harness, or copy transcript data. A source endpoint missing from the registered domain returns a protocol error rather than panicking or emitting an incomplete domain.

Added regression coverage checks corpus structural validation, canonical rename and clear behavior, archive/child/ephemeral retention, missing-summary omission, invalid-summary and missing-domain errors, actual deletion, preserved legacy `sessions` membership, endpoint-scoped identity, and the public inventory frame pairing visible rows with the full retained corpus from one store snapshot. Coordinating validation of presentation/web passed; the final batch receipt records the serial shared-target validation. No ranking result, full-corpus consumer, multi-endpoint union, pagination behavior, or end-to-end demo parity is claimed by this source slice.
